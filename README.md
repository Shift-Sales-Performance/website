# Shift Sales Performance website

The public website for Shift Sales Performance, served by GitHub Pages.

- `index.html` is the whole site (styles, scripts and images are inline).
- The contact form opens the visitor's email app with their enquiry addressed to info@shiftsalesperformance.com.au.
- While the site is a preview, `index.html` carries a `noindex` tag so search engines skip it. Remove it, and add a `CNAME` file containing `shiftsalesperformance.com.au`, when the domain moves here.
